# uabb-separator

## Responsibility

Renders a presentational horizontal divider line: a `uabb-separator-parent` > `uabb-separator` pair, with the inner element styled by a configurable `border-top` (thickness/style/color), percentage width, and container `text-align` for alignment. No JS, no state, no AJAX, no security surface.
